# jarvis-like-ai
A simple jarvis like ai that can open websites, play songs and read news with the help of newsapi

It is simple ai that can do:
                      - Open webpages like: "YOUTUBE", "GOOGLE", "GEEKSFORGEEKS".
                      - Play music from YOUTUBE (Currently): "HASEEN", "EHSAAS", "DHUNDHALA"
                      - Read news with the help of "NewsAPI".

The basic required modules are mentioned in the "requiremens.txt".
